# RPL Orçamentos PRO 9.0
Extraia este ZIP na raiz do repositório Codespaces, execute git add ., git commit -m "RPL PRO 9.0" e git push origin main. Actions gera o APK debug.
Conta local com usuário e senha, catálogo ilustrativo (SVGs genéricos reutilizados por família), fotos próprias, preços manuais, rascunho local e PDF nativo Android 10+ em Downloads/RPL. Compartilhamento abre WhatsApp quando instalado. Não há sincronização em nuvem nem cotação automática. O APK precisa ser compilado e testado em aparelho; não foi validado neste ambiente.
